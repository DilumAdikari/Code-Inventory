## Reporting a Vulnerability

If you discover a security vulnerability within Code-Inventory, please report it responsibly. 

* **Where to report:** Send an email to Dilumadikari610@gmail.com (or use GitHub's private vulnerability reporting feature). Please **do not** open a public GitHub issue for security vulnerabilities.
* **What to include:** Please provide a summary of the vulnerability, a description of the steps to reproduce, and any potential impact.
* **Response time:** You can expect an initial response within 48 hours acknowledging your report, followed by regular updates on progress as we work on a fix.
